## 4. 이 프로젝트에서 배운 것

에이전트가 겪고 알아낸 것 중 코드·문서에 안 남는 것(재현 명령, 도구 버릇, 테스트 함정). 메모리로 저장한 것은 여기 적지 않는다(`~/config/claude/memory/교환_기록.md`로 공유).

- 기존 `app/`·`server/`에는 이전 초안(`어질러진 방`: `Bin`/`RoomState`/`/api/*`)이 구현되어 있고, `docs/requirements.md`는 `Book`/`CollageState`/`/v1/*`로 재정의한다.
- `app/`은 `vitest run`, `server/`는 `./gradlew test`로 각각 디렉터리 안에서 실행한다(`H-ENV-04`).

## 5. PC별 함정 (win ↔ mac)

공통 차이는 `~/config/README.md`. 이 프로젝트에만 있는 것만 적는다.

| 상황 | win | mac |
| --- | --- | --- |
| 환경 변수 붙여 실행 | PowerShell 불가 → Git Bash에서 `VAR=x cmd` | 그대로 |
| 회사/보안 프록시 뒤 링크 미리보기 | `JAVA_OPTS=-Djavax.net.ssl.trustStoreType=Windows-ROOT` | 그대로 |

## 6. 새 PC에서 시작할 때

```bash
git clone https://github.com/Hunseokc/dontcleanmydesk.git && cd dontcleanmydesk
# ~/config 동기화로 AI 협업 규칙 복원 후:
cd app && npm install && npm test
cd ../server && ./gradlew test
```

- 저장소 밖에 있어서 손으로 옮겨야 하는 것: `.env`, `~/config/dontcleanmydesk/` (`.sync-map` 자동 동기화)
