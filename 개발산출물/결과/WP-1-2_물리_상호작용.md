## 가드 변이와 원복

`app/`에서 물리·배치 테스트는 `node node_modules/vitest/vitest.mjs run src/desk/preview/<파일>.test.ts`로 실행했다. 라우트 변이는 별도 경로로 export하고 `serve -s`에서 `playwright test … --grep '0크기 복귀'`로 실행했다. 각 원본은 바이트 단위로 되돌렸고 관련 제품 소스 `git diff --exit-code`로 확인했다.
