dontcleanmydesk · 책상 없는(기본 UI 바탕색) 콜라주 & 와이어프레임 일체형 시안

왜 책상이 나왔나? 와이어프레임(frame.jpeg)에는 나무 책상이 없지만, 초기 레거시 코드(app/src/desk/의 6레이어 나무 책상·나뭇잎·솔방울)가 requirements.md §3 S-03와 WP-1에 합쳐지면서 첫 단계부터 나무결 책상이 등장했습니다.
아래에서 책상을 아예 없애고 기본 UI 바탕색만 쓰는 버전(후보 A·B)과 Codex 추천 C안(어두운 회반죽 매트)을 나란히 비교해 보세요.

비교 1. 콜라주 바탕 — 책상 없음(기본 UI 바탕색) vs 어두운 매트 확인 (A 채택 · B 노트 속지 프리셋 보존)

확정 기조. 나무결·얼룩·솔방울·나뭇잎을 제거하고 기본 UI 바탕색(#F0EEEA) 위에 양면 노트(#FAF9F6)만 올립니다. 속지는 A 무지(기본)와 B 모눈(노트 안쪽만 격자, 바깥은 단색 UI 바탕 유지) 프리셋으로 제공합니다.
